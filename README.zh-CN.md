# look-first

[English](README.md) · [简体中文](README.zh-CN.md)

一个让 AI 写代码前先看现有代码的 Agent Skill。

它要求 AI 在新增代码前，先检查相关实现和调用方，寻找可以复用的能力，再用解决当前问题所需的最小设计完成任务。它能减少重复造轮子、过早抽象、为假想未来增加配置，以及无关重构；当现有语义确实不匹配时，也允许进行最小的新建。

## 安装

```bash
npx skills add wiks-ai/look-first --skill look-first
```

部分客户端也支持直接安装仓库默认技能：

```bash
npx skills add wiks-ai/look-first
```

## 它改变了什么

Skill 提供一个有界的工作流程：

1. 明确需求行为和改动边界。
2. 读取目标文件，以及最相关的调用方、依赖和附近模式。
3. 现有能力匹配时直接复用。
4. 只差一个小能力时，优先兼容扩展现有职责归属。
5. 只有语义确实不同或相关区域为空时才新建实现。
6. 控制设计规模，并验证受影响的行为。

它不要求 API Key、项目配置、测试套件、特定语言或外部服务，只使用宿主 Agent 已有的仓库读取、搜索和编辑能力。信息足够后会停止搜索，不会把每个小任务变成审批仪式。

## 使用前后对比

没有这个 Skill 时，AI 可能因为没有检查现有工具而新增第二套请求封装，也可能为了一个调用点引入策略模式或注册表。

使用这个 Skill 后，AI 会先检查相关代码；如果现有封装匹配就复用，只有在旧语义不适用时才新建函数，并保持设计与当前需求相称。

## 范围

`look-first` 用于约束实现决策。它不承诺所有改动都能复用旧代码，也不替代项目自身的评审和测试规范。
